# Where to start

The project's notes live in [`docs/`](docs/), written as an Obsidian vault (plain
Markdown with links between notes). Open the `docs` folder in Obsidian with "Open
folder as vault" to see the project as a graph, or just read the files.

Read in this order:

1. [`docs/Project Map.md`](docs/Project%20Map.md): the hub and mind map.
2. [`docs/Goal and Requirements.md`](docs/Goal%20and%20Requirements.md): what is being built.
3. [`docs/Progress.md`](docs/Progress.md): what is done and the exact next step.
   **Keep this one up to date at every checkpoint.**

Then the note for the part you are working on: Architecture, Matching Pipeline,
Backend, Frontend, Evaluation and Testing, Decisions.
